Before your first capture

SourceBraid reads the active page only after you choose Save or Download. Save sends its URL, extracted content, tags, notes, and captured assets directly to the GitHub repository you configure. Download keeps the Markdown local. It may request the selected website and relevant assets to prepare the clip. Nothing is sent to a SourceBraid content server.

Privacy policy

GitHub repository

Choose a private repository with an initial commit. The token needs Contents: Read and write for that repository only. PDF support also needs Workflows: Read and write for its first installation. Setup guide · Create a token

Optional source APIs

Credentials are stored in Chrome local storage and sent only to GitHub or, when configured, Ghost or Blogger endpoints. Exported plugin configs never contain tokens.
