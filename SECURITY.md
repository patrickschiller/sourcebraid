# Security Policy

Please do not report access tokens, private archive content, or other sensitive
data in a public issue.

For suspected vulnerabilities, open a private GitHub security advisory for
`patrickschiller/sourcebraid`. Include the affected component, reproduction
steps using sanitized data, and the expected impact.

SourceBraid credentials should be fine-grained GitHub tokens restricted to the
intended private archive repository. Revoke a token immediately if it may have
been exposed.
